# FitTrack
A simple fitness tracking web app developed as a Class 12 Computer Science AISSCE project.

## Features
- User login
- Daily activity logging
- Fitness statistics and graphs
- Local user leaderboard

## Technologies
Python, Flask, SQLite, SQL, HTML, CSS, JavaScript, Jinja2, and Chart.js.

## Run
```bash
cd fittrack-aissce
python3 app.py
```
Then click on the link displayed on the terminal.
